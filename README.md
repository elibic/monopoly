# מונופול בעברית 🎩

משחק מונופול ישראלי מלא בדפדפן — נגד המחשב, מותאם לילדים, בעברית מלאה (RTL).

ממומש לפי חוברת ההוראות המקורית של המשחק (קודקוד/Hasbro), כולל:

- 🎲 לוח ישראלי מלא: 40 משבצות, 22 רחובות ב-8 ערים, רכבות, חברת חשמל וחברת המים
- 💳 בלי מזומן! לכל שחקן כרטיס אשראי וחשבון בנק, והתשלומים עוברים אוטומטית
- 🔨 מכירות פומביות כשמוותרים על קנייה
- 🏠 בנייה שווה של בתים ומלונות, עם מלאי מוגבל (32 בתים, 12 מלונות)
- 🏦 משכנתאות עם 10% ריבית, מסחר בין שחקנים, פשיטת רגל
- 👮 כלא: קנס, דאבל או כרטיס "צא מהכלא חינם"; דאבל שלישי שולח לכלא
- 🃏 16 קלפי הפתעה ו-16 קלפי תיבת המזל
- 🤖 עד 3 יריבי מחשב שקונים, בונים, מציעים במכירות ואפילו מציעים עסקאות
- 🔊 קריינות בעברית באיכות AI: קליפים מוקלטים מראש בקול נוירוני
  (he-IL-Hila של Edge TTS) — תור, קניות, שכר דירה, כלא וכל 32 הקלפים,
  בלשון נכונה לבן/בת. אם קליפ חסר — נסיגה אוטומטית לקול הדפדפן עם
  טקסט מנוקד. יצירת הקליפים רצה חינם ב-GitHub Actions
  (`tools/generate_voice.py`)
- ✨ עיצוב "שולחן משחק": קוביות תלת-ממד מתגלגלות, כלים שמדלגים משבצת-משבצת,
  קלפי הפתעה מתהפכים, יתרות שנספרות, וקונפטי בניצחון
- 🏦 **מצב חינוך פיננסי** (בחירה במסך הפתיחה): הילד יכול להשקיע כסף
  בשלושה מסלולי סיכון — 🐷 קופת חיסכון, 🌳 פיקדון ו-🚀 מניות של ארבע
  חברות מומצאות — ולראות פעם בסבב מה קרה לכסף שלו **ולמה**: כל שינוי
  מקבל הסבר בשפת ילדים ("קיץ לוהט, כולם קונים גלידה — ההשקעה שלך גדלה
  ב-10 ₪, כלומר 20%"). הסיכון אמיתי אך מוגן: אפשר להפסיד, ההשקעה לעולם
  לא נמחקת, ולאורך זמן השוק נוטה לעלות — בדיוק כמו במציאות
- ✨ חלונית "מה חדש?" עם יומן חמש הגרסאות האחרונות, שנפתחת פעם אחת אחרי
  כל עדכון

## איך משחקים?

🌐 **באינטרנט (חינם):** המשחק מתפרסם אוטומטית ב-GitHub Pages:
**https://elibic.github.io/monopoly/**

💾 **המשחק נשמר לבד** בדפדפן אחרי כל מהלך — אפשר לסגור את הדף ולחזור מתי
שרוצים, והמשחק ממשיך בדיוק מאותה נקודה. איפוס נעשה רק ידנית בכפתור 🔄.

💻 **אופליין (בלי אינטרנט):** המשחק עצמאי לחלוטין — גופנים, קריינות
וכל הנכסים שמורים בתוך התיקייה, בלי שום תלות חיצונית. כדי לשחק בלי
רשת:

1. בעמוד הריפו ב-GitHub: **Code → Download ZIP**
2. מחלצים את הקובץ
3. פותחים את `index.html` בדפדפן (לחיצה כפולה) — וזהו, המשחק רץ לגמרי
   מקומית, כולל הקריינות הקולית.

אפשר גם דרך שרת מקומי (מומלץ אם משהו לא נטען):

```bash
python3 -m http.server 8000
# ואז נכנסים אל http://localhost:8000
```

## מבנה הקוד

| קובץ | תפקיד |
|------|--------|
| `js/data.js` | נתוני הלוח, הקלפים והקבועים — כל שינוי שם/מחיר נעשה כאן |
| `js/engine.js` | מנוע המשחק: כל החוקים, ללא תלות בדפדפן |
| `js/ai.js` | החלטות שחקן המחשב |
| `js/ui.js` | תצוגה: לוח, כרטיסי אשראי, דיאלוגים, קול |
| `js/main.js` | חיבור: לולאת תורות וקלט |
| `beta/` | גרסת נסיון — עותק מלא של המשחק לפיתוח תכונות חדשות לפני שהן עולות לגרסה הראשית |
| `tests/engine.test.mjs` | בדיקות המנוע |
| `fonts/` | Secular One + Varela Round (רישיון OFL) באחסון עצמי — עובד בלי אינטרנט |

## מצב חינוך פיננסי — איך זה בנוי?

המטרה חינוכית: ללמד ילד בן 7 מה שווה כסף, מה זו ריבית, ולמה כדאי
להשקיע לטווח ארוך — בלי להסתיר שאפשר גם להפסיד.

| מסלול | סיכון | תשואה ממוצעת לסבב | מה זה מלמד |
|-------|-------|-------------------|-------------|
| 🐷 קופת חיסכון | אפס | ‎+2% קבוע (מינימום ‎1 ₪) | כסף ששוכב בצד גדל לבד, לאט ובבטחה |
| 🌳 פיקדון | נמוך | ‎+4% | בדרך כלל עולה, לפעמים נח — סבלנות משתלמת |
| 🚀 מניות | גבוה | ‎+8% (טווח ‎30%- עד ‎40%+) | סיכון גבוה = סיכוי גבוה, אבל גם ירידות |

- **הסבר לכל שינוי**: אף רווח או הפסד לא מוצג בלי סיפור שמסביר אותו,
  ולצד כל אחוז מוצג גם הסכום בשקלים.
- **אירועי חדשות** (בערך בכל סבב שלישי) מזיזים חברה אחת חזק לכיוון אחד,
  עם כרזה וקריינות — ככה נלמד שאירועים בעולם משפיעים על השוק.
- **פיזור סיכונים**: ארבע חברות שונות, כדי שאפשר יהיה ללמוד בפועל
  שלא שמים את כל הכסף במקום אחד.
- **אין מחיקה**: ערך השקעה לא יורד מתחת ל-1 ₪, וההפסד המרבי בסבב הוא חצי.
- הנתונים (מסלולים, חברות, חדשות והסברים) יושבים כולם ב-`FINANCE`
  שב-`js/data.js` — כוונון האיזון נעשה שם, בלי לגעת במנוע.
